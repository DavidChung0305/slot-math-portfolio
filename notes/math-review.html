01樣本空間與等機率

Day 3

5 軸，第 i 軸長 Lᵢ。一轉 = 5 個停止位置 (s₁, …, s₅)
總組合數 T = L₁ · L₂ · L₃ · L₄ · L₅ = 30⁵ = 24,300,000     ← 乘法原理

P(s₁, …, s₅) = P(s₁) × … × P(s₅)        ← 獨立
             = (1/L₁) × … × (1/L₅)      ← 均勻
             = 1/T
兩個假設均勻（每格 1/Lᵢ）＋獨立（各軸互不影響），由 RNG 保證。這樣才能用「組合數 ÷ 總組合數」算機率。
隨機 ≠ 等機率軸 1 位置 0 的機率若是 1/2，獨立仍成立但均勻失效，P 就不是 1/T，數組合數的方法全部失效。

02計數：乘法原理、剛好 vs 至少、互斥

Day 3

乘法原理

分步驟選、每步選法互不影響 → 總數 = 各步選法數相乘。

Lines：剛好 k 連

例：Lᵢ = 10、A 每軸 cᵢ = 2
剛好 3 連 = c₁ c₂ c₃ (L₄ − c₄) L₅ = 2·2·2·8·10 = 640     ← 軸 4 必須「不是 A」
剛好 4 連 = c₁ c₂ c₃ c₄ (L₅ − c₅) = 128
剛好 5 連 = c₁ c₂ c₃ c₄ c₅        = 32
至少 3 連 = c₁ c₂ c₃ L₄ L₅        = 800 = 640 + 128 + 32   ← 驗算
互斥才能相加同一符號只算最長，所以「剛好 3/4/5 連」互斥，RTP 才能把各獎項直接加總。分項加總 = 另一種算法，是最好用的驗算。

Ways：一路 = 每軸各挑一個

軸 1 有 2 個 H1、軸 2 有 2 個、軸 3 有 1 個、軸 4 沒有
剛好 3 連 H1 = 2 × 2 × 1 = 4 路
5×3 盤面每軸 3 列 → 3⁵ = 243 條路徑（243 Ways）

03期望值、線性、指示變數

Day 1、Day 3、Day 4

E[X] = Σ x · P(X = x)                    ← 平均值
總和 = 個數 × 平均                        ← 等機率時 E[X] = 總和 / 總組合數
E[X + Y] = E[X] + E[Y]                   ← 線性：永遠成立，不需要獨立、不需要互斥
E[cX] = c · E[X]                         ← 常數可以提出來

指示變數：期望值 = 機率

1{事件} = 事件發生 1，否則 0
E[1{事件}] = 1 · P(事件) + 0 · P(不發生) = P(事件)

雙重計數：每個 A 被看到幾次

把 L 個停止位置的「視窗內 A 個數」全部加起來：
  橫著加（每個視窗）：不規則
  直著加（每個 A）  ：每個 A 剛好被 3 個視窗看到 → 總和 = 3c
E[Xᵢ] = 3cᵢ / Lᵢ                         ← Xᵢ = 第 i 軸視窗內 A 個數

E[X] 和 P(X ≥ 1) 不一樣

軸 1 的 S 在第 5、7 格，L = 30
X = I₅ + I₇        （I₅ = 第 5 格那顆 S 在視窗內）
E[X] = 3/30 + 3/30 = 6/30 = 0.2            ← 線性
P(X=1) = 4/30、P(X=2) = 1/30（停在 5 時兩個都看到）、P(X≥1) = 5/30
驗算：E[X] = 1·4/30 + 2·1/30 = 6/30 ✓

E[X] = 1·P(X=1) + 2·P(X=2) + 3·P(X=3)
P(X≥1) = 1·P(X=1) + 1·P(X=2) + 1·P(X=3)
→ E[X] ≥ P(X ≥ 1)，只有不可能看到 2 個以上時才相等
1 − 3c/L 不是 P(X = 0)[A, K, A, Q, J]：1 − 6/5 = −0.2，負的機率。3c/L 是平均個數，不是機率。

04獨立與同分布

Day 3、Day 6

同分布 → 任何函數的期望值都一樣：E[D₁] = E[D₂]、E[D₁²] = E[D₂²]
獨立   → 乘積的期望值可以拆：E[XY] = E[X] · E[Y]

骰子例

D₁、D₂ 兩顆骰子，同分布且獨立
E[D] = 3.5        E[D²] = (1² + … + 6²)/6 = 91/6 ≈ 15.17

E[D₁·D₂] = Σ Σ i·j / 36 = (1+…+6)(1+…+6)/36 = 21·21/36 = 12.25 = 3.5²   ← 獨立，可拆
E[D₁·D₁] = 15.17 ≠ 12.25                                                ← 自己跟自己不獨立
差 = 15.17 − 12.25 = 2.92 = Var(D)

應用：Ways 全部盤面的總路數

一盤剛好 3 連的路數 = X₁ · X₂ · X₃ · 1{X₄ = 0}
總和 = T × E[X₁ X₂ X₃ 1{X₄=0}]
     = T × E[X₁]·E[X₂]·E[X₃]·P(X₄=0)                 ← 各軸獨立才能拆
     = T × (3c₁/L₁)(3c₂/L₂)(3c₃/L₃)(N₄/L₄)
     = Sum₁ · Sum₂ · Sum₃ · N₄ · L₅                   ← Sumᵢ = 3cᵢ，L 約掉

H1：6 × 6 × 6 × 24 × 30 = 155,520 路
最後一軸乘 L，不是 Sum剛好 3 連只要求軸 4 斷掉，軸 5 停哪都算 1 次。

05看不到的停止位置數 N（間隔通式）

Day 3

P(Xᵢ = 0) = Nᵢ / Lᵢ        N = 視窗內完全沒有 A 的停止位置數

捲軸看成圓圈，相鄰兩個 A 之間夾 g 格非 A（c 個 A → c 個間隔）
長度 g 的間隔放得下 g − 2 個「連續 3 格都不是 A」的視窗
N = Σ max(0, gⱼ − 2)                     （視窗 r 列：gⱼ − (r − 1)）

L − 3c = Σ (gⱼ − 2)                      ← 捷徑
捷徑正確 ⇔ 每個 gⱼ ≥ 2 ⇔ 任兩個 A 的距離 ≥ 列數
例：長度 10，2 個 Q 堆疊在 0、1 → 間隔 0 和 8
  N = 0 + 6 = 6           捷徑 10 − 6 = 4 ✗（重疊的視窗扣了兩次）
對 RTP 的影響E[Xᵢ] = 3cᵢ/Lᵢ 只看個數；P(Xᵢ = 0) 看排列。個數相同、排列不同的兩款遊戲 RTP 可以不同。堆疊：看不到的機率變高，看到就是多個 → 波動度上升。
有 Wild 後 N ≠ L − Sum同符號間距 ≥ 3，但 W 和 A 可以相鄰：軸 2 第 5 格 A、第 6 格 W，N = 30 − 15 + 2 = 17。N 一定要直接數。

06RTP 與 Ways

Day 4

W = 一轉派彩（隨機變數）
E[W] = Σ w(組合) · (1/T) = 總派彩 / T        ← 等機率
RTP  = E[W] / bet = 總派彩 / (T × bet)
莊家優勢 = 1 − RTP

Ways：總派彩 = Σ（各獎項總路數 × 每路賠率）

小例子：1 軸 4 格、押 50、只有第 4 格派 100
  100 / (4 × 50) = 0.5      E[W] = 25，25/50 = 0.5 ✓
總派彩是錢，不是中獎盤面數中獎盤面數 / 總組合數 = 命中頻率，不是 RTP。

Wild：把「K」換成「K 或 W」

Sumᵢ = 視窗內「K 或 W」個數加總      Nᵢ = 視窗內「沒有 K 也沒有 W」的停止位置數

每軸（2–5）加 1 個 W → 每個符號 Sum +3，但倍數不同：
  H1：6 → 9 (×1.5)      K：12 → 15 (×1.25)
  5 連 H1 ×1.5⁴ ≈ 5.06    5 連 K ×1.25⁴ ≈ 2.44
H1 整體 ×2.99 = 以原派彩為權重的加權平均（3 連 ×1.97、4 連 ×2.95、5 連 ×5.06）

結論：Wild 對稀有高分符號與長連線放大最多 → RTP 和波動度都上升。

本遊戲：主遊戲連線 49.25% + Scatter 2.12% = RTP_spin 51.37%

07命中頻率、全期望值、幾何分布

Day 4

命中頻率 = P(至少中一個獎)。各符號中獎不互斥，不能相加（排容要 2⁸ − 1 = 255 項）→ 直接數盤面。只看前 3 軸：30³ = 27,000 種。

中獎 ⇔ ∃ s ∈ 視窗₁，(s 或 W ∈ 視窗₂) 且 (s 或 W ∈ 視窗₃)
加 S 前：13,953 / 27,000 = 51.68%       加 S 後：47.63%（1 in 2.10）

全期望值：中獎時平均贏幾倍

E[W] = P(H) · E[W | H] + P(沒中) · E[W | 沒中]
     = P(H) · E[W | H] + P(沒中) · 0
E[W | H] = RTP / 命中頻率 = 0.5629 / 0.5168 ≈ 1.09 倍押注

         RTP    命中頻率   中獎時平均
遊戲 A   96%     50%       1.92 倍     常中、中得小
遊戲 B   96%     10%       9.6 倍      少中、中得大

幾何分布與「反面」技巧

每轉成功機率 p → 平均 1/p 轉成功一次
n 轉內至少一次 = 1 − (1 − p)ⁿ

例：p = 1/200 → 平均 200 轉；100 轉內至少一次 = 1 − (199/200)¹⁰⁰ ≈ 0.394

08二項分布與 Scatter

Day 4

每軸看得到 S 的機率 q，各軸獨立 → X = S 的個數 ~ Binomial(5, q)
P(X = k) = C(5, k) · qᵏ · (1 − q)⁵⁻ᵏ

q = 3/30 = 0.1
  P(3) = 10 × 0.001 × 0.81 = 0.0081
  P(4) = 5 × 0.0001 × 0.9  = 0.00045
  P(5) = 0.00001
  P(≥3) = 0.00856 = 1 − P(≤2)       → 平均 ≈ 117 轉觸發

RTP_scatter = Σ P(k) · mₖ = 0.0081·2 + 0.00045·10 + 0.00001·50 = 2.12%
q = 3c/L 的前提3c/L 其實是 E[視窗內 S 個數]；同符號間距 ≥ 3 時才等於 P(至少 1 個)。第 5、7 格的例子 q = 5/30，不是 6/30。

各軸 q 不同：Poisson 二項分布

二項分布要求每次成功機率相同。不同時用全機率法則一軸一軸拆：
例：軸 1–4 q = 0.1，軸 5 q = 0.2，P(剛好 3 個)
  軸 5 有 S：0.2 × C(4,2)·0.1²·0.9² = 0.00972
  軸 5 沒 S：0.8 × C(4,3)·0.1³·0.9  = 0.00288
  合計 0.0126
Python：dist = np.convolve(dist, [1 − qᵢ, qᵢ])  逐軸做

09條件期望

Day 5

E[Y | A] = Σ y · P(Y = y | A) = Σ y · P(Y = y 且 A) / P(A)

骰子例：E[點數 | ≥ 4] = (4 + 5 + 6)/3 = 5

若 A 不發生時 Y = 0：
  E[Y] = P(A)·E[Y|A] + P(非A)·0   →   E[Y | A] = E[Y] / P(A)

E[送幾次 | 觸發] = r / P(觸發) = 0.08795 / 0.00856 ≈ 10.27

10免費遊戲與重觸發

Day 5、Day 6

規則：3/4/5 個 S 送 10/15/20 次；贏分 ×2；可重觸發；同一套捲軸

A = 一轉送出幾次免費轉（0、10、15、20）
r = E[A] = 0.0081×10 + 0.00045×15 + 0.00001×20 = 0.08795

平均總轉數 m（面試題 4）

方法一（等比級數）：1 + r + r² + … = 1/(1 − r)
方法二（第一步分析）：m = 1 + r · m   →   m = 1/(1 − r) ≈ 1.0964
         ↑   ↑
     這 1 轉  平均送 r 轉，每轉再各自平均帶出 m 轉（自我相似：捲軸沒記憶）
收斂條件 r < 1；r ≥ 1 期望值無限大 → 實務加上限，改用有限狀態馬可夫鏈

Wald 等式

E[Z₁ + … + Z_A] = E[A] · E[Z]       條件：每次的量跟次數 A 無關
（先固定 A = a：線性 → a·E[Z]；再對 A 平均 → E[A]·E[Z]）

1 次免費轉的期望贏分 E[Z]

Z = 1 次免費轉＋它所有子孫的總贏分 = 2X + (Z₁ + … + Z_A)

E[Z] = 2E[X] + r · E[Z]   →   E[Z] = 2E[X] / (1 − r) = 2E[X] · m
     = 2 × 0.51367 / 0.91205 ≈ 1.1264

RTP_FG 與總 RTP

每次主遊戲轉從免費遊戲拿到：r · E[Z] = r/(1−r) × 2 × RTP_spin
                          = 0.08795 × 1.1264 ≈ 9.91%

總 RTP = E[T] = E[X] + r · E[Z] = 0.51367 + 0.09907 = 0.61274 = 61.27%

11變異數與標準差

       = E[X²] − E[X]²          捷徑：先平方再平均 − 先平均再平方

12免費遊戲（含重觸發）的變異數

Day 6 步驟 5

目標：每次主遊戲轉的總贏分 T 的 Var(T) = E[T²] − E[T]²。E[T] 已有，T 裡面有免費遊戲 → 要先算 E[Z²]。

每個隨機變數的意思

主遊戲轉 1 次 ┌──────────────────────────────┐ │ 盤面（5 軸 × 3 格） │ │ → X：這個盤面贏幾倍押注 │ │ → A：這個盤面送幾次免費轉 │ └──────────────────────────────┘ 送 A 次免費轉 / | \ Z₁ Z₂ ... Z_A ← 每個 Zⱼ = 那一次免費轉 + 它重觸發的所有子孫 └──────┴───────┘ S = Z₁ + Z₂ + … + Z_A
符號意思期望值
X這個盤面本身贏幾倍押注（連線＋Scatter，不含免費遊戲）0.51367
A這個盤面送幾次免費轉（0、10、15、20）r = 0.08795
Zⱼ / Z1 次免費轉連同所有子孫的總贏分（已含 ×2）1.1264
S送出去的免費轉加總 Z₁ + … + Z_A（A = 0 時為 0）r · E[Z]
T主遊戲轉 1 次的總贏分 = X + S0.61274
 
T = X  + S     ← 主遊戲轉：×1
Z = 2X + S     ← 免費轉：×2

例：盤面 3 個 S + 小連線 → X = 2.4、A = 10
    10 次免費轉 S = 30（其中 Z₇ = 25 含重觸發）→ T = 32.4
  • Zⱼ 同分布：結構跟 Z 一樣 → E[Zⱼ] = E[Z]、E[Zⱼ²] = E[Z²]
  • Zⱼ 獨立：不同分支彼此獨立，也跟產生它們的盤面（X、A）獨立
  • X 和 A 不獨立：同一盤面的 S 個數同時決定 Scatter 派彩和送幾轉

步驟 1：展開

Z² = (2X + S)² = 4X² + 4XS + S²
E[Z²] = 4E[X²] + 4E[XS] + E[S²]

步驟 2：E[S²]（先固定 A = a，再對 A 平均）

(Z₁ + … + Z_a)²：平方項 a 個、交叉項（ZᵢZⱼ, i ≠ j，分開算）a(a−1) 個
  A = 3 例：Z₁² + Z₂² + Z₃² + (Z₁Z₂ + Z₂Z₁ + Z₁Z₃ + Z₃Z₁ + Z₂Z₃ + Z₃Z₂)

平方項 E[Zᵢ²] = E[Z²]（同分布）       交叉項 E[ZᵢZⱼ] = E[Z]²（獨立）
E[S² | A = a] = a · E[Z²] + a(a−1) · E[Z]²

E[S²] = Σₐ P(A = a)·[ a·E[Z²] + a(a−1)·E[Z]² ]
      = E[A]·E[Z²] + E[A(A−1)]·E[Z]²
      = r·E[Z²]    + E[A(A−1)]·E[Z]²

注意 E[A(A−1)] ≠ r(r−1)，要用 A 的分布算：Σ P(A = a)·a(a−1)。

步驟 3：E[XS]（先固定盤面，再對盤面平均）

X 和 A 不獨立 → E[XS] ≠ E[X]·E[S]

盤面固定 → X = x、A = a 是已知數字
  E[S | A = a] = a · E[Z]
  E[XS | 盤面] = x · a · E[Z]          ← x 是常數，提出來
對所有盤面平均：E[XS] = E[XA] · E[Z]    （E[XA] 要逐盤面算，比 E[X]·E[A] 大）

步驟 4：組合、移項

E[Z²] = 4E[X²] + 4E[XA]·E[Z] + r·E[Z²] + E[A(A−1)]·E[Z]²

E[Z²]·(1 − r) = 4E[X²] + 4E[XA]·E[Z] + E[A(A−1)]·E[Z]²

E[Z²] = [ 4E[X²] + 4E[XA]·E[Z] + E[A(A−1)]·E[Z]² ] / (1 − r)

  4E[X²]            這一轉自己的贏分平方（×2 平方 → ×4）
  4E[XA]·E[Z]       這一轉贏分 × 子孫贏分（X、A 相關）
  E[A(A−1)]·E[Z]²   不同子孫分支之間的交叉項
  ÷ (1 − r)         每個子孫自己的平方項 r·E[Z²] 移項過來

跟 E[Z] = 2E[X]/(1−r) 一樣，分母 (1 − r) 是重觸發無限延續造成的放大。

步驟 5：E[T²] 與 Var(T)

T² = (X + S)² = X² + 2XS + S²

E[T²] = E[X²] + 2E[XA]·E[Z] + r·E[Z²] + E[A(A−1)]·E[Z]²     ← 不用移項
Var(T) = E[T²] − E[T]²        σ_total = √Var(T)
為什麼 E[T²] 不用移項、E[Z²] 要T 的子孫是免費轉（Z），不是主遊戲轉（T）：主遊戲轉只是整棵樹的根，T 不自我相似。Z 的子孫還是免費轉，跟 Z 自己一樣，所以 E[Z²] 出現在兩邊。

步驟 6：逐盤面算零件

Python：w = 每盤贏分（點）、A = 每盤送幾次（all_board_awards），n = 30⁵
  E[XA]     = (w * A).sum() / n / bet        ← X 出現一次，除一次 bet
  E[A(A−1)] = (A * (A − 1)).sum() / n        ← A 跟押注無關

E[XA] = 0.29330   vs   E[X]·E[A] = 0.04518   ← 正相關，大 6.5 倍
  粗估（只算 Scatter 派彩）：0.0081×10×2 + 0.00045×15×10 + 0.00001×20×50 ≈ 0.24
  Cov(X, A) = E[XA] − E[X]·E[A] > 0

E[A(A−1)] 手算：0.0081×90 + 0.00045×210 + 0.00001×380 = 0.8273   ✓ 與 Python 一致
  （r(r−1) 是負的，不可能是答案）

結果

E[Z²]   = 10.6718
E[T²]   = 4.4895
Var(T)  = 4.4895 − 0.61274² = 4.1141
σ_total = 2.0283

模擬 200 萬次主遊戲轉（含重觸發）：
  RTP 0.61279，95% CI [0.60999, 0.61560] ∋ 0.61274 ✓      σ 2.0247（差 0.2%）✓

                 RTP       σ
主遊戲 X       51.37%   1.2556
含免費遊戲 T   61.27%   2.0283    ← RTP +10 個百分點，σ +62%、變異數 ×2.6
為什麼免費遊戲讓 σ 大增免費遊戲的 9.91% 集中在 0.86% 的轉（觸發時平均約 11.6 倍押注）。變異數看平方，罕見的大值平方後被放大最多。同樣的 RTP 從主遊戲搬到免費遊戲，σ 大幅上升。
模擬 σ 為什麼不像 RTP 那麼準尾巴很重（偶爾一次贏幾百倍），樣本標準差的抽樣誤差比平均值大，0.2% 的差距正常。

Day 2、Day 6

名詞

名詞意思本遊戲的例子
分布隨機變數每個值出現的機率（整張表）T：99% 是 0～小額，偶爾幾百倍
μ（期望值）長期平均RTP = 0.61274
σ（標準差）單次結果離平均多遠的典型距離σ_total = 2.0283
i.i.d.獨立且同分布：每轉互不影響、規則一樣RNG 每轉各自抽停止位置
樣本平均 T̄N 轉實際贏分的平均 = N 轉的實際返還率玩 1,000 轉贏回 0.55 倍
標準誤 σ/√NT̄ 的標準差：N 轉平均會晃多少N = 10⁶ → 0.0020
常態分布 N(μ, σ²)鐘形曲線，由 μ、σ 完全決定T̄（N 夠大時）
標準常態 N(0, 1)μ = 0、σ = 1 的常態
標準化（z 分數）(值 − 平均) ÷ 標準差 = 離平均幾個 σ
1.96N(0,1) 中間 95% 的邊界：P(−1.96 ≤ Z ≤ 1.96) = 0.95
信心水準區間要涵蓋的機率（95%、90%…）90% 用 1.645、99% 用 2.576
半寬（誤差範圍）1.96·σ/√N，區間 = 中心 ± 半寬
VI（波動度指數）1.96·σ：轉 1 次的 95% 半寬；除以 √N 就是 N 轉的半寬3.976
重尾極端大值雖罕見但不夠罕見，拉高 σ、拖慢收斂免費遊戲重觸發

定理 1：變異數的兩條規則 → σ/√N

規則 a：Var(cX) = c²·Var(X)
  證：E[(cX)²] − E[cX]² = c²E[X²] − c²E[X]² = c²·Var(X)

規則 b：Var(X + Y) = Var(X) + Var(Y) + 2Cov(X, Y)
        獨立 → Cov = 0 → Var(X + Y) = Var(X) + Var(Y)

N 轉相加（每轉獨立）：Var(T₁ + … + T_N) = N·σ²            ← 規則 b
N 轉平均：Var(T̄) = Var((T₁ + … + T_N)/N) = N·σ² / N² = σ²/N   ← 規則 a，c = 1/N
         σ(T̄) = σ / √N
為什麼是 √N 不是 N變異數縮小 N 倍，標準差是開根號，只縮小 √N 倍。精度要好 10 倍，轉數要多 100 倍。

定理 2：大數法則（LLN）

i.i.d.、期望值 μ 存在 → N → ∞ 時 T̄ → μ
白話：轉得夠多，實際返還率會接近 RTP

只說「會靠近」，沒說 N 轉時離多遠。離多遠要靠中央極限定理。

定理 3：中央極限定理（CLT）

i.i.d.、μ 和 σ 存在 → N 夠大時
  T̄ 近似 N(μ, σ²/N)        不管單次 T 原本長什麼樣子

骰子例：1 顆骰子 1～6 平的（均勻）
       2 顆平均：三角形（3.5 最多）
       30 顆平均：已經很像鐘形，μ = 3.5、σ = 1.708/√30 ≈ 0.31
N 要「夠大」，尾巴越重要越大單轉 T 極度偏斜（大部分小、偶爾幾百倍）。N 小時 T̄ 還不是鐘形，用 1.96 算出的區間不可靠。

組合：95% 區間

標準化：Z = (T̄ − μ) / (σ/√N) ≈ N(0, 1)
P(−1.96 ≤ Z ≤ 1.96) = 0.95
→ P( μ − 1.96σ/√N ≤ T̄ ≤ μ + 1.96σ/√N ) = 0.95

VI = 1.96σ        95% 區間 = μ ± VI/√N

兩種用法（方向相反）

(1) 預測：已知 RTP，玩家 N 轉的實際返還率落在哪？
    RTP ± VI/√N
    N = 1,000：      61.27% ± 12.6%   → [48.7%, 73.8%]
    N = 1,000,000：  61.27% ± 0.40%   → [60.87%, 61.67%]

(2) 驗證：模擬得到 T̄，理論 RTP 合不合理？（信賴區間）
    T̄ ± 1.96·s/√N        s = 模擬算出的樣本標準差
    200 萬轉：0.61279 ± 0.0028 → [0.60999, 0.61560] ∋ 0.61274 ✓

(3) 反推轉數：要 ±e 的精度
    VI/√N ≤ e  →  N ≥ (VI/e)²
    ±1%：N ≥ (3.976/0.01)² ≈ 158,000 轉
面試題 2：模擬 95.8%、理論 96% 對嗎？要看 N 和 σ。算 95.8% ± 1.96σ/√N，96% 在區間內就合理；不在就是邏輯或 RNG 有問題。只說「差 0.2% 很接近」不算答案。

練習

Q1：10,000 轉的 95% 區間（RTP 61.27%、VI 3.976）
    半寬 = 3.976 / √10,000 = 0.03976 → [57.29%, 65.25%]
    轉數 ×10（1,000 → 10,000），寬度只縮成約 1/3（√10 ≈ 3.16）

Q2：VI = 10 和 VI = 2，要 ±1% 的精度
    (10/0.01)² = 1,000,000 轉     (2/0.01)² = 40,000 轉     → 25 倍
    VI 跟標準差成正比，轉數跟變異數（σ²）成正比：VI 差 5 倍，轉數差 25 倍

15面試問答

兩款 RTP 都是 96% 的遊戲差在哪？
平均一樣，波動度（σ）和命中頻率不同。σ 大：中獎少但獎大，資金起伏大；也可以用 RTP ÷ 命中頻率看中獎時平均贏幾倍。實例：本遊戲主遊戲 σ 1.2556，加上只佔 9.91% RTP 的免費遊戲後 σ 2.0283，RTP 越集中在罕見的特色遊戲，σ 越大。
RTP 和 σ 一樣的兩款遊戲，玩起來會不同嗎？
會。兩個數字描述不了形狀：例如 50% 贏 0／50% 贏 2，和 90% 贏 0.667／10% 贏 4，平均和變異數都是 1，但後者命中 100%、90% 是 LDW。要看派彩區間分佈。
派彩區間分佈為什麼加免費遊戲後要用模擬？
平均和變異數可以用第一步分析的公式避開窮舉，但整張分布沒有捷徑；10 次免費轉就有 (30⁵)¹⁰ 種組合，重觸發還沒有上限。模擬 N 次數比例，每列附 p̂ ± 1.96√(p̂(1−p̂)/N)。
高波動遊戲為什麼要跑更多模擬轉數？
要 ±e 的精度需要 N ≥ (VI/e)²，轉數跟變異數成正比。VI 大 5 倍，轉數要 25 倍。
X 和 A 的共變異數是正還是負？為什麼？
正。觸發的盤面一定有 Scatter 派彩，A 大時 X 也大。E[XA] = 0.2933 遠大於 E[X]·E[A] = 0.0452。
每轉觸發機率 1/200，平均幾轉觸發？100 轉內至少一次的機率？
幾何分布平均 1/p = 200 轉。至少一次 = 1 − (199/200)¹⁰⁰ ≈ 39.4%（用反面算）。
為什麼命中頻率不能把各符號的命中機率加起來？
同一轉可能多個符號同時中，事件不互斥。排容要 255 項，所以直接窮舉前 3 軸 27,000 種盤面。
Wild 對哪些獎項放大最多？
稀有符號與長連線：每軸 Sum 都 +3，相對倍數 H1 ×1.5、K ×1.25，5 連再取 4 次方。RTP 和波動度一起上升。
用兩種方法推導含重觸發的免費遊戲平均轉數與期望贏分。
(1) 等比級數 1 + r + r² + … = 1/(1−r)。(2) 第一步分析 m = 1 + r·m。期望贏分同理：E[Z] = 2E[X] + r·E[Z] → 2E[X]/(1−r)。r ≥ 1 不收斂。
為什麼 E[Y | 觸發] = E[Y] / P(觸發)？
全期望值：E[Y] = P(觸發)·E[Y|觸發] + P(沒觸發)·0，沒觸發時 Y = 0，移項即得。
為什麼 E[XS] 不能寫成 E[X]·E[S]？
X 和 A 由同一盤面決定，不獨立。條件在盤面上：E[XS] = E[XA]·E[Z]。
E[(Z₁+…+Z_A)²] 怎麼算？
固定 A = a：a 個平方項各 E[Z²]、a(a−1) 個交叉項各 E[Z]²。對 A 平均：E[A]·E[Z²] + E[A(A−1)]·E[Z]²（隨機和的二階動差）。
同分布和獨立差在哪？
同分布 → 期望值相同（E[Zᵢ²] = E[Z²]）。獨立 → 乘積可拆（E[ZᵢZⱼ] = E[Zᵢ]E[Zⱼ]）。自己跟自己永遠不獨立：E[D²] − E[D]² = Var(D)。
為什麼 E[Z²] 的方程式要移項，E[T²] 不用？
免費轉的子孫還是免費轉，跟自己同分布，所以 E[Z²] 出現在兩邊。主遊戲轉的子孫是免費轉不是主遊戲轉，右邊只有已解出的 E[Z²]，直接代入。
